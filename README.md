# Celestial Misfits website

The website for the Celestial Misfits Rust server: plain HTML pages and images, hosted with GitHub Pages.

- `index.html`: home (season banner, seasons calendar, arsenal, donate)
- `guide.html`: player guide (every player command)
- `help.html`: You're not alone (crisis lines, 214 Life, Jump S.T.A.R.T.)
- `img/`: banners and logo
